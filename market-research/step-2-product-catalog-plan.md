## 0. Executive Summary

The launch catalog contains **15 prompt packs across 5 job categories, 5 practical ebooks (36–52 pages), 3 bundles, and 2 lead magnets** — 25 sellable products plus a free-funnel. Structure follows the Step 1 research: niche over volume, tiered price points per category, ebooks positioned as the premium "method" products (priced above packs, per catalog spec), and bundles at a visible ~27% discount. Every product ships with quality-checked formatting (Word+PDF for packs, PDF+EPUB for ebooks), and the SKU system is built to scale across future categories.

**Catalog totals:** GH₵ 2,710 in individual prices · 3 bundles worth GH₵ 1,235 combined · lead magnets free

## 1. Pricing Philosophy (from Step 1 research)

| Research principle (Step 1) | How it shows up in this catalog |
|---|---|
| Niche beats volume | Packs are 12–45 prompts per single job task — never "10,000 mega packs" |
| Tiered options per category | Starter packs (12–15 prompts) → System packs (35–45 prompts) → Ebook (premium method) |
| Ebooks priced higher than packs | Per catalog spec, ebooks carry the full method + workbook and are the premium product in each category (GH₵ 165–245 vs packs GH₵ 75–225) |
| Below-cheap signals garbage | No product below GH₵ 75 (~$6.7); free lead magnets are clearly "samples," not products |
| Bundles at visible discount | ~26–27% off combined value on every bundle |
| Regional pricing | Local-currency prices set for Ghanaian purchasing power; USD storefront in Wave 3 |

**Why ebooks cost more than packs:** a prompt pack is a tool (copy-paste, 15–45 items); an ebook is a system (method + walkthroughs + checklists + the prompts embedded). The spec requires ebook > pack, and this is defensible: ebooks remain far below the $17–43 Kindle price-fatigue zone and ship with a free first chapter to de-risk purchase.

## 6. Quality Standard Checklists

### 6A. Prompt pack quality standards (every pack, every prompt)
- [ ] **Context instructions** — each prompt includes explicit role, goal, target audience, tone, and output constraints; no prompt is a bare instruction.
- [ ] **Variable placeholders** — inputs in `[BRACKETED]` placeholders with one-line fill-in instructions (e.g., `[CLIENT INDUSTRY]`, `[SCOPE]`).
- [ ] **Example outputs** — each prompt ships with at least one annotated sample output showing what "good" looks like and what to customize.
- [ ] **Consistent formatting** — uniform per-prompt template: *Title · When to use · The prompt · How to customize · Example output*; mono-spaced prompt blocks; one prompt per page.
- [ ] **Anti-generic constraints** — banned-phrase lists and output-format specs built into the prompts (kills the "AI tell").
- [ ] **Testing** — every prompt tested on ChatGPT, Claude, and Gemini; test results and known limitations documented in a README.
- [ ] **Value test** — each prompt passes the Step 1 test: "the user cannot get 80% of this value by asking the AI directly."
- [ ] **Files** — Word (.docx) + PDF, no watermarks, print-safe, and a copy-paste plain-text section in the PDF.
- [ ] **Updates** — changelog + 12 months of free prompt updates by email (defuses "prompts break when models update").

### 6B. Ebook quality standards (every ebook)
- [ ] **Clear table of contents** — chapter list with page numbers; hyperlinked in the EPUB.
- [ ] **Cover page** — designed cover, title page, copyright/disclaimer page, author/about page.
- [ ] **Professional formatting** — consistent heading hierarchy (H1/H2/H3), no orphaned headings, consistent spacing, page numbers.
- [ ] **Readable fonts** — body ≥ 11pt, 1.5 line spacing, comfortable margins; EPUB tested on Kindle, Kobo, and Apple Books.
- [ ] **Consistent headings** — every chapter opens with a chapter number + title; section headings follow one style.
- [ ] **Actionable content on every page** — each page carries at least one takeaway, template, prompt, or checklist; no filler pages.
- [ ] **Chapter structure** — 5–7 chapters per book; every chapter ends with "Action Steps."
- [ ] **Editing pass** — two-pass human proofread; zero typos; AI-tell-free writing (the book practices what it preaches).
- [ ] **Formats** — PDF (6×9 print-ready) + EPUB (reflowable, DRM-free).
- [ ] **Sample** — Chapter 1 available free on the product page (de-risks purchase).

## 8. Future Catalog Expansion Roadmap

### Wave 1 — Launch (weeks 0–4) · *this catalog*

### Wave 2 — New categories & formats (weeks 5–10)
- **HR/Recruiters category** (highest-evidence runner-up from Step 1): 2 starter packs (JD writer, interview & screening) + 1 system pack + ebook *The Recruiter's AI Desk* (40 pp).

- **BND-SMB-01** Small Business Bundle and **BND-DEV-01** Dev Bundle from existing inventory (no new content needed).
- **Sell-side:** Paystack/MoMo checkout integration if not already at launch.

### Wave 3 — Depth & subscription (months 3–4)
- **Lawyers category:** 2 packs focused on safe drafting workflows (hallucination-avoidance) — high caution, high willingness to pay.
- **Second ebooks per category:** *Freelance Pricing Without Guessing* (FRE), *The Content Calendar That Runs Itself* (MKT), *Analytics for Creators* (CRE), *SQL Interview Prep* (DEV).
- **All-Access Launch Bundle:** everything at ~30% off (value GH₵ 2,710 → ~GH₵ 1,899).
- **Prompt Updates Club** subscription: GH₵ 99/month — quarterly prompt refreshes + 2 new packs/year (defuses the staleness objection, builds recurring revenue).
- **International storefront:** USD pricing tier for global buyers using research benchmarks ($9–19 starter packs, $19–29 systems, $24.99–39.99 bundles).

### Wave 4 — Scale (months 5+)
- **Courses:** *Prompt Mastery for African Professionals* (GH₵ 499) built from the top ebook content.
- **Custom prompt service:** done-for-you packs from GH₵ 549 (high-margin, no inventory).
- **Community:** paid membership (GH₵ 79/month) with monthly prompt drops + live Q&A.
- **Localization:** French (for francophone West Africa) and Swahili editions of the top 3 ebooks; regional currency support (NGN, XOF).
- **Print-on-demand** versions of the top 2 ebooks for the local market.

### Catalog scalability (how the structure grows)
- **SKU naming:** `PKG-{CAT}-{NN}` / `EBK-{CAT}-{NN}` / `BND-{CAT}-{NN}` / `FRE-{NN}` — new categories just add a code (HR, TCH, LAW, CSM).
- **File convention:** `{SKU}-{name-slug}-{lang}-{format}` e.g. `PKG-FRE-03-freelance-business-engine-en-docx.pdf` — version-safe, store-ready.
- **Store folders:** `catalog/packs/`, `catalog/ebooks/`, `catalog/bundles/`, `catalog/free/`, each with a `manifest.json`/spreadsheet inventory list (SKU, title, price, formats, status).
- **Bundle rule stays constant:** System pack + starter pack bonus + matching ebook at ~27% off — repeatable for every future category.
